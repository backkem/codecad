Open-source 2D CAD that runs in the browser. Every drawing operation is a function call. Script it, automate it, point an AI at it.

Open App GitHub

DWG in the browser

Opens .dwg files (R13-R2018) with infinite vector zoom. GPU rendering via Vello/WebGPU, CPU fallback via egui.

Scriptable API

Every operation is cad.addLine(), cad.addCircle(), etc. Drive it from the console, your own code, or a language model.

Real-time sync

Optional Rust server syncs edits across browsers via Yrs CRDT over WebTransport. Server-side JS scripting via Wasmtime sandbox.

Draw with code

// Flange plate: center bore, bolt circle, dimensions
cad.addCircle([0, 0], 150, { layer: "FLANGE" })
cad.addCircle([0, 0],  40, { layer: "BORE" })

for (let i = 0; i < 8; i++) {
  const a = i * Math.PI / 4
  cad.addCircle([110 * Math.cos(a), 110 * Math.sin(a)], 8)
}

cad.measure([0, 0], [150, 0], { offset: 30 })
